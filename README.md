# 🚀 Azure PHP Web Deployment (Nginx + PHP-FPM)

## 📌 Project Overview
This project demonstrates the deployment of a PHP-based web application on Microsoft Azure using a Linux Virtual Machine.

The setup includes configuring Nginx as a web server, integrating PHP-FPM for dynamic content processing, and deploying a live website accessible via public IP.

---

## 🧰 Tech Stack
- Microsoft Azure (VM)
- Ubuntu 24.04
- Nginx
- PHP 8.3 (PHP-FPM)
- SSH
- GitHub (Documentation)

---

## ⚙️ Deployment Steps
1. Create Azure Virtual Machine
2. Connect via SSH
3. Install Nginx
4. Install PHP (php-fpm, php-mysql)
5. Configure Nginx for PHP
6. Upload website files
7. Set permissions
8. Restart services
